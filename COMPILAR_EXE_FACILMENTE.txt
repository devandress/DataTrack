📋 OPCIÓN 1: Solo el EXE (Más fácil)
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

EN WINDOWS - EN UNA CARPETA CON TODOS LOS ARCHIVOS DEL PROYECTO:

1. Abre CMD (símbolo del sistema)
2. Navega a la carpeta del proyecto:
   
   cd "C:\ruta\a\DataTrack"

3. Ejecuta:

   build_exe.bat

4. Espera 10-15 minutos
5. Te aparecerá un menú:
   - Opción 1: Nada (solo el EXE)
   - Opción 2: Carpeta portable (MEJOR)
   - Opción 3: Instalador MSI

📦 OPCIÓN 2: Carpeta Portable (Recomendado)
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

EN WINDOWS - MISMO PROCEDIMIENTO:

1. Ejecuta: build_exe.bat
2. Elige opción 2 (carpeta portable)
3. Script crea carpeta: DataTrack-Portable/
4. Comprime la carpeta en ZIP
5. Compartir ZIP con tu amigo

Tu amigo:
1. Descarga DataTrack-Portable.zip
2. Extrae la carpeta
3. Haz doble-click en DataTrack.exe
4. ¡Listo!

🚀 PASO A PASO COMPLETO
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

PASO 1: Preparar en Linux
─────────────────────────

```bash
# 1. Verifica que todo está bien
python3 app.py

# 2. Se abre navegador automáticamente en http://localhost:5000
# 3. Carga un video pequeño y prueba dibujar un polígono
# 4. Si todo funciona → Continúa con Paso 2

# Termina con Ctrl+C
```

PASO 2: Transferir a Windows
──────────────────────────────

Copia TODO el proyecto a una carpeta en Windows:
- app.py
- build_exe.bat ✨ (nuevo)
- DataTrack.iss
- build_msi.ps1
- modules/
- static/
- templates/
- config/
- yolo11*.pt (IMPORTANTE)

PASO 3: Compilar en Windows
─────────────────────────────

1. Abre CMD en la carpeta del proyecto
2. Ejecuta:

   build_exe.bat

3. Espera (puede tomar 15-20 minutos)
4. Elige opción 2 (carpeta portable)
5. Se crea: DataTrack-Portable/

PASO 4: Preparar para compartir
─────────────────────────────────

Opción A - Carpeta comprimida:
1. Click derecho en DataTrack-Portable
2. Enviar a → Carpeta comprimida
3. Se crea: DataTrack-Portable.zip
4. Compartir ZIP con amigo

Opción B - Archivo solo EXE:
1. Ir a dist/
2. Copiar DataTrack.exe
3. Pegar en carpeta vacía
4. Agregar modelos (yolo11n.pt mínimo)
5. Comprimir todo
