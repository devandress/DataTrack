📦 COMPILACIÓN EN WINDOWS
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

Requisitos:
✓ Windows 10/11 64-bit
✓ Inno Setup 6 instalado
✓ Carpeta del proyecto con:
  - app.py ✓ (modificado)
  - build_msi.ps1 ✓ (modificado)
  - DataTrack.iss ✓ (ya existe)
  - Modelos YOLO (yolo11n.pt, etc.)
  - Carpetas: config/, templates/, static/, modules/

Comando (en PowerShell Admin):
```powershell
cd "C:\ruta\a\DataTrack"
powershell -ExecutionPolicy Bypass -File build_msi.ps1
```

Resultado:
✓ dist\DataTrack.exe (ejecutable)
✓ Output\DataTrack-Installer.exe (instalador ← COMPARTIR ESTO)

En tu Linux, antes de pasar a Windows:

```bash

# Deberías ver:
# [HARDWARE] {...}
# 🚀 DataTrack iniciado
# 📱 Accediendo a: http://localhost:5000
```

💡 NOTAS TÉCNICAS
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

• webbrowser es módulo built-in de Python (sin dependencias extra)
• Se ejecuta en thread separado para no bloquear Flask
• --console permite ver mensajes de debug en Windows
• Delay de 2 segundos permite que Flask inicie antes
