🚀 INSTRUCCIONES PARA GENERAR EL INSTALADOR EN WINDOWS:
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

PASO 1: Descargar e instalar Inno Setup
  • Ir a: https://www.innosetup.com/isdl.php
  • Descargar e instalar (versión 6.x)

PASO 2: Abrir PowerShell como Administrador
  • Windows Key + X → PowerShell (Admin)
  • O: Windows Key + S → Buscar "PowerShell" → Click derecho → Admin

PASO 3: Navegar a la carpeta del proyecto
  cd "C:\ruta\a\DataTrack"

PASO 4: Ejecutar el compilador
  powershell -ExecutionPolicy Bypass -File build_msi.ps1

PASO 5: Esperar a que compile
  • Esto puede tomar 10-15 minutos
  • Se generará: Output\DataTrack-Installer.exe

PASO 6: ¡Listo!
  • El instalador estará en: Output\DataTrack-Installer.exe
  • Comparte este archivo con tu amigo

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
