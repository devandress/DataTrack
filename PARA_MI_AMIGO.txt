🚀 ¿QUÉ ES ESTO?
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

DataTrack es un sistema inteligente que:
• Carga videos de tránsito
• Dibuja áreas de interés (polígonos)
• Detecta vehículos automáticamente
• Cuenta cuántos vehículos pasan por cada área
• Genera reportes con los datos

✅ INSTALACIÓN (Windows)
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

1. Recibe el archivo: DataTrack-Installer.exe
2. Haz doble clic en él
3. Sigue los pasos (Next → Next → Finish)
4. Se creará un acceso directo en el escritorio
5. Haz doble clic en el acceso directo para iniciar

¡ESO ES TODO! 🎉

💻 PRIMER USO
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

1. Ejecuta DataTrack
   → Se abrirá automáticamente en tu navegador
   → Dirección: http://localhost:5000

2. En la interfaz verás:
   • Selector de VIDEO (carga tu video de tránsito)
   • HERRAMIENTAS de dibujo (para marcar áreas)
   • CONFIGURACIÓN (confianza de detección, etc)
   • RESULTADOS (tabla con conteos)

════════════════════════════════════════════════════════════════

📹 CÓMO USAR
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

PASO 1: Cargar Video
  → Click en "Seleccionar Video"
  → Elige un archivo .mp4, .avi, .mov o .mkv
  → Se muestra vista previa en la interfaz

PASO 2: Dibujar Áreas (Polígonos)
  → Elige herramienta:
    • RECTÁNGULO: Drag para dibujar
    • POLÍGONO: Click en cada vértice, doble-click para terminar
  
  → Ejemplo:
    - Entrada de carril → Polígono 1 (azul)
    - Salida de carril  → Polígono 2 (dorado)
    - Zona de espera    → Polígono 3 (rojo)

PASO 3: Configurar Detección
  → Confianza: % de precisión (70-90 es normal)
  → Skip Frames: Procesa cada 1, 2 o 3 frames
  → Modelo: Tamaño de red YOLO (nano/small/medium/large)

PASO 4: Procesar Video
  → Click en "PROCESAR VIDEO"
  → Verás barra de progreso
  → Cuando termine, aparecen RESULTADOS

PASO 5: Ver Resultados
  → Tabla con:
    • Nombre del área (Polígono 1, etc)
    • Autos detectados
    • Motos detectadas
    • Otros vehículos
  
  → Video anotado: muestra boxes alrededor de autos
  → Puedes descargar todo

❓ PREGUNTAS FRECUENTES
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

P: ¿Qué formatos de video soporta?
R: MP4, AVI, MOV, MKV (video estándar)

P: ¿Puedo dibujar varias áreas?
R: Sí, tantas como necesites

P: ¿Qué datos saca del video?
R: Contador de vehículos por tipo y por área

P: ¿El video se guarda?
R: Se genera uno "anotado" (con cuadros de detección)

P: ¿Qué es "Confianza"?
R: % de seguridad en que es realmente un auto

P: ¿El programa necesita internet?
R: No, todo se ejecuta localmente

P: ¿Cuál modelo YOLO uso?
R: Empieza con "Pequeño" (nano) y sube si necesitas más precisión

⚙️ REQUISITOS DEL SISTEMA
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

✓ Windows 10/11 (64 bits)
✓ 8 GB RAM mínimo (16 GB recomendado)
✓ GPU NVIDIA (opcional pero recomendado para velocidad)
✓ 5 GB espacio libre (para modelos + videos)
✓ Navegador web (Chrome, Edge, Firefox)

🔧 SOLUCIÓN DE PROBLEMAS
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

"Pantalla en blanco"
→ Espera 10 segundos a que cargue
→ Refresh F5 en el navegador

"El puerto 5000 está ocupado"
→ Cierra la app
→ Espera 5 segundos
→ Abre de nuevo

"Video muy lento"
→ Usa modelo "Pequeño" (nano)
→ Aumenta "Skip Frames" a 3
→ Reduce resolución del video

"Muy pocos vehículos detectados"
→ Baja la Confianza a 50-60%
→ Prueba modelo más grande
