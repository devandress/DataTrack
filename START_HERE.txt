⚡ FORMA MÁS RÁPIDA
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

EN LINUX (Ahora):
  1. python3 app.py
  2. Se abre navegador
  3. Prueba cargar video
  4. Ctrl+C para terminar

EN WINDOWS (PC compiladora):
  1. Copia carpeta DataTrack completa
  2. build_exe.bat
  3. Elige opción 2
  4. Espera 20 minutos
  5. compress_portable.bat
  6. Se crea: DataTrack-Portable.zip

PARA TU AMIGO:
  1. Descarga DataTrack-Portable.zip (~2 GB)
  2. Extrae la carpeta
  3. DataTrack.exe (doble-click)
  4. ¡LISTO!

❓ ¿CUÁL DIFERENCIA?
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

EXE solo (Opción 1):
  ✓ Archivo único
  ✓ Tu amigo: ejecuta directamente
  ✗ Menos ordenado

Carpeta Portable (Opción 2) ✨ RECOMENDADO:
  ✓ Todo junto y ordenado
  ✓ Fácil de compartir
  ✓ Tu amigo: extrae y ejecuta
  ✓ Mejor para distribución

Instalador MSI (Opción 3):
  ✓ Muy profesional
  ✓ Crea acceso directo
  ✓ Se desinstala fácil
  ✗ Más pesado
  ✗ Más complejo
